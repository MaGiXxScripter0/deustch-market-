# Импорт реального каталога

Этот магазин показывает только товары, которые клиент сможет забрать в `Berlin-Mitte`.
Не импортируйте маркетинговые данные поставщика без проверки: артикул, цена, остаток и
готовность к выдаче должны подтверждаться магазином.

## Формат исходного CSV

Файл — UTF-8, разделитель `;`, одна строка — одна продаваемая позиция. Первая строка:

```text
sku;gtin;brand;name_de;category_slug;price_gross;sale_unit;base_price;base_unit;base_quantity;stock_berlin;pickup_available;pickup_lead_time;image_url;short_description_de;description_de;specs_json;search_aliases;is_featured;is_active;source_url
```

Минимальный пример:

```text
00002886;4003982001399;Knauf;Bauplatte GKB 12,5 mm;trockenbau-platten;8.95;Stück;5.74;m²;1.56;19;true;Abholbereit in 2 Stunden;https://example.com/gkb.jpg;Universelle Ausbauplatte für Wand und Decke.;Formstabile Gipskartonplatte für trockene Innenbereiche.;"{""Stärke"":""12,5 mm"",""Format"":""1250 × 2600 mm""}";Gipsplatte|GK Platte;true;true;https://example.com/knauf-gkb
```

## Правила качества перед импортом

1. `sku` уникален и совпадает с артикулом поставщика или внутренним SKU магазина.
2. `brand`, `name_de`, размер, единица продажи и характеристики сверены с карточкой
   производителя. Цена — цена именно вашего магазина, а не цена конкурента.
3. `stock_berlin` — фактический доступный остаток для самовывоза. Ноль означает, что
   кнопку заказа для позиции нужно отключить.
4. `pickup_available` должен быть `true` только для позиций, которые продавец может
   собрать в обозначенный срок. Доставку и склад другого города не добавляем.
5. В `image_url` используйте собственные фотографии или изображения, на которые есть
   лицензия. Ссылки на фотографии конкурентов не копируются.
6. `specs_json` содержит только строковые пары «свойство → значение»; например,
   `{"Länge":"2 m","Material":"Titanzink"}`.
7. `gtin` и `source_url` фиксируют происхождение карточки: GTIN содержит 8–14 цифр,
   ссылка ведёт на официальный источник производителя или поставщика. Поля могут быть пустыми,
   если такого источника нет.

## Массовая загрузка 400 позиций

1. Экспортировать ассортимент из учётной системы в этот формат.
2. Прогнать CSV через проверку: дубликаты SKU, пустые обязательные поля, отрицательные
   цены/остатки, неизвестные категории и некорректный JSON.
3. Загрузить сначала 10 позиций в тестовую среду, проверить поиск, карточку, корзину и
   резервирование остатка.
4. После сверки загрузить весь каталог и перед публикацией проверить по выборке не
   менее 20 товаров: цена, наличие, изображение и готовность к самовывозу.

Для первого запуска магазин уже содержит 24 референсные позиции реальных производителей.
Окончательные 400 карточек должны поступать от владельца магазина или его поставщиков:
это единственный надёжный источник для локальных цен и остатков.
